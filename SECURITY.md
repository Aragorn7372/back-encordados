# Security Policy

## Reporting a Vulnerability

We take the security of BackEncordados seriously. If you discover a security vulnerability, please report it privately using **GitHub's Private Vulnerability Reporting** feature:

1. Go to the repository's **Security** tab
2. Click **Report a vulnerability**
3. Fill in the details of the vulnerability

This ensures the issue is only visible to the repository maintainers until it's resolved.

## What to include

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue (if possible)
- Any relevant code snippets, logs, or screenshots
- The version(s) of the software affected

## Response expectations

- We will acknowledge receipt of your report within **48 hours**
- We will work on a fix and keep you informed of progress
- Once resolved, we will publish a security advisory and credit you as the reporter (if desired)

## Scope

The following are considered in scope:
- The BackEncordados API and its endpoints

The following are out of scope:
- Social engineering attacks
- Denial of service attacks
- Physical security attacks

## Disclosure policy

We follow a **coordinated disclosure** model:
- Please do not share details of the vulnerability publicly until we have released a fix
- We will collaborate with you on the timeline for public disclosure
